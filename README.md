# Paidipelli Ruthvik Portfolio

GitHub Pages-ready responsive portfolio.

## Upload
Upload all files in this folder to your GitHub repository.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.

Included:
- Responsive portfolio
- Home, Services, About and Skills
- Six project cards
- Project filtering
- LinkedIn certification links
- GitHub project links
- Resume download
- Mobile navigation
- Scroll animations
- Back-to-top button

Project visuals are CSS-based, so no external image files are required.
